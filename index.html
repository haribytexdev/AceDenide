Smart India Hackathon 2026 · Problem Statement 26145

We are building IRIS for SIH 2026.

IRIS is an AI-based system that detects malware, DDoS and other network attacks from one-way (unidirectional) IP traffic. It brings Zeek/Snort, two ML models, an AI decision agent and Wazuh together in one Docker Compose stack. A React SOC dashboard shows a simple 0–100 risk score, an attack timeline and MITRE ATT&CK mapping, so analysts know what to fix first.

How we work

The same five steps on every project, so you always know what happens next.

  1. Step 1

    Listen

    We start with your goals, your users and what has not worked before.

  2. Step 2

    Plan

    Scope, structure and a clear timeline, agreed before any code is written.

  3. Step 3

    Design

    Simple, readable screens you can react to early and change cheaply.

  4. Step 4

    Build

    Clean code, tested as we go, with regular updates in plain language.

  5. Step 5

    Launch

    We ship it, check it and stay close while it settles in.
